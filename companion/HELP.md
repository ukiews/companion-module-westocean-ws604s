# West Ocean WS-604S

Enter the clock's IP address or hostname. Companion connects to the built-in Remote Console on TCP port 81. The Remote Console on firmware V2.0.1 requires only the clock address.

Use **Start countdown** with a duration like `30`, `5:00`, or `1:30:00`. The action starts immediately after entering the duration and replaces any active timer. Durations from 1 second to 99:59 use one-second steps. Longer durations use whole minutes up to 99 hours 59 minutes.

Use **Load countdown without starting** before a cue, then use **Pause / resume timer** at the cue to start it. A single-run countdown returns to wall time when it finishes.

**Show elapsed minutes** holds a supplied value until the next update. Through 99 minutes, only the right two digits are filled. **Blink silently** uses a one-second cycle. With sound enabled before the first blink, the module mutes during blinking and restores sound when you clear the display or start a countdown.

Use **Start saved countdown preset** for M1 (seconds), M2 (minutes), or M3 (hours). **Start stopwatch (M4)** starts counting up from zero. **Pause / resume timer** toggles playback, and **Cancel timer and show time** returns to the time display.

Ready-to-use 30-second, 5-minute, and 10-minute countdown buttons are in **Presets**. **Mirror clock display** shows the clock's live display on a Companion button.
